# DAO Fund Manager Contract

A contract that manages DAO funds by allocating budgets to specific purposes
and enforcing governance-approved spending rules.

## Key Functions
- `create-allocation` — Define a new fund allocation or budget
- `fund-allocation` — Assign treasury funds to an allocation
- `request-release` — Submit a request to use allocated funds
- `approve-release` — Governance approval for fund usage
- `execute-release` — Transfer funds after approval

Designed for DAOs that require structured budgeting, accountability, and
controlled fund execution.
